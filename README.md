Лабораторная работа №4: DevOps-автоматизация с использованием bash-скриптов, systemd и Ansible.

## Что реализовано

- создан bash-скрипт для запуска HTTP-сервиса;
- настроен systemd-unit для автозапуска сервиса;
- добавлен healthcheck-скрипт;
- подготовлен Ansible inventory;
- создан Ansible playbook для автоматического развёртывания сервиса.
